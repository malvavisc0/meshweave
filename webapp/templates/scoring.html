Scoring Methodology

MeshWeave analyzes websites across 12 factors to produce two composite scores: AEO (Answer Engine Optimization) and GEO (Generative Engine Optimization). Each score is rated 0–100.

AEO Score (Answer Engine Optimization)

Measures readiness for Google AI Overviews, featured snippets, and voice assistant answers.

Factor Weight Auto-scored?
Snippet / AI Overview Capture Rate 30% No — needs GSC data
Schema Implementation 20% ✅ From crawl (JSON-LD coverage)
Content Structure Quality 20% ✅ From crawl (headings, word count, images)
Query Match Precision 15% No — needs keyword analysis
Voice Selection Rate 10% No — needs voice testing
Freshness / Update Frequency 5% ⚠️ Partial (dateModified in JSON-LD)

AEO ratings

Score Rating
0–20 Poor
21–40 Below Average
41–60 Average
61–80 Strong
81–100 Excellent

GEO Score (Generative Engine Optimization)

Measures how visible and citation-worthy your content is to AI engines like ChatGPT, Claude, and Perplexity.

Factor Weight Auto-scored?
AI Citation Frequency & Quality 30% No — needs external monitoring
Topical Authority / Entity Coverage 20% ✅ From schema + content breadth
E-E-A-T Signals 15% ⚠️ Partial (org, author, reviews)
LLM Crawl Accessibility 15% ✅ robots.txt, llms.txt, sitemap
Content Depth & Originality 10% ✅ Words, lists, tables, code blocks
Cross-Platform Entity Consistency 10% ✅ sameAs, name/desc consistency

How composite scores are calculated

Each score is a weighted sum of its six factor scores. When manual inputs are missing (e.g., no GSC data for Capture Rate), the weights are renormalized across available auto-scored factors to produce an "auto-only" score.

For example, if only 4 of 6 AEO factors have values, the composite uses those 4 factors with their weights scaled to sum to 100%. This means the auto-only score reflects the best assessment possible from crawl data alone.

What we analyze automatically

From a single URL crawl, the engine extracts and scores:

  • Schema coverage — which pages have JSON-LD, which types, FAQ/HowTo presence
  • Content structure — heading hierarchy, word counts, image alt text, lists, tables
  • Entity signals — Organization schema, sameAs links, name/description consistency
  • E-E-A-T indicators — author info, reviews, ratings, contact/privacy pages
  • LLM accessibility — robots.txt bot policies, llms.txt, sitemap availability
  • Freshness — dateModified/datePublished from structured data
  • Content depth — average words per page, code blocks, original data signals

Optional manual inputs

For a complete score, you can supplement auto-scored data with:

Input Where to find it Affects
Snippet/AI Overview Capture Rate Google Search Console → Performance → Search Appearance AEO (30%)
Query Match Precision "People Also Ask" analysis for target keywords AEO (15%)
Voice Selection Rate Test queries on Google Assistant, Siri, Alexa AEO (10%)
AI Citation Frequency Monitor ChatGPT, Claude, Perplexity citations GEO (30%)

Recommendations

Each analysis generates prioritized recommendations based on the raw scoring data. Recommendations are ranked by estimated point impact:

  • High priority — fixes that could improve scores by 10–15 points (e.g., adding FAQ schema, Organization JSON-LD)
  • Medium priority — fixes with 5–10 point impact (e.g., enriching thin content, adding alt text)
  • Low priority — refinements with 3–5 point impact (e.g., adding sameAs links)
